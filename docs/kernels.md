# Kernels and weight formats

What runs where when Qwen3.8-Flash-Next is loaded with `load_qwen38` (`src/moe_expert_streaming/qwen38.py`), and which
weights come from the converted safetensors checkpoint and which from Strata's GGUF.

Everything here is pure Python on the host side: device work is either a [Hub kernel](https://huggingface.co/docs/kernels)
(`kernels.get_kernel`) or Metal source in this package compiled at first use with `torch.mps.compile_shader`. The
patches are installed by `qwen38.apply()` (idempotent, called by `load_qwen38`); each one falls back to the model's own
code when its conditions do not hold (another device, another dtype, grad enabled, an unexpected shape).

## Weights: safetensors or GGUF

`load_qwen38(converted, ...)` always reads the converted checkpoint (`scripts/convert_fp8.py`):

| Directory | Contents | Used for |
|---|---|---|
| `dense/` | the non-expert weights in BF16 (safetensors) | every dense weight not replaced by the GGUF (below); quantized to 8-bit `MetalConfig` at load on MPS (`dense_bits=8`, the default there), kept BF16 elsewhere |
| `experts-q{bits}/` | routed experts, MLX affine (3-bit by default, group 64) | the routed experts, unless `gguf_experts=True` (then only their layout is read) |
| `ngram/` | the n-gram embedding table | read from disk on demand (`DiskEmbedding`) |

Two options swap parts of it for Strata's GGUF (`Qwen3.8-Flash-Next-GSQ-RCO-IQ3_XXS-*.gguf`):

| Option | Replaced | By | Kept from safetensors |
|---|---|---|---|
| `gguf_dense=<gguf path(s)>` (MPS) | the large dense projections: Gated DeltaNet `in_proj_qkv`, `in_proj_z`, `out_proj`; attention `q/k/v/o_proj`; shared-expert `gate/up/down_proj`; `lm_head` | `GgufLinear` (`gguf_dense.py`), the GGUF blocks as stored (Q4_K-Q6_K, IQ4_XS, IQ3_S, ...) | Gated DeltaNet `in_proj_a/b`, hyper-connections, routers, indexer, norms, embeddings; and any GGUF tensor of a type ggml's Metal gemv does not cover (8 projections in Q2_0, logged as `kept 8 (['type 42'])`) |
| `gguf_experts=True` (needs `gguf_dense`) | the routed experts | Strata's `<gguf>.experts` file: IQ2/IQ3 gate/up, IQ4_NL or Q2_0 down, streamed into a per-size-class device cache (`gguf_experts.py`) | nothing for the experts (`experts-q3/` only gives the layout) |

The published numbers use both (`--gguf-dense G --gguf-experts` in `scripts/bench.py`). Without them the model runs
on 8-bit `MetalConfig` dense layers and 3-bit MLX experts.

## Hub kernels

| Kernel | Used for | When |
|---|---|---|
| `kernels-community/mlx-quantization-metal-kernels` v2: `quantized_matmul` | 8-bit `MetalConfig` dense layers (`metal_linear.py`); the hyper-connection's fused down + inject projection for one token | MPS, `dense_bits` set. The fused projection is single-token only: bf16 `quantized_matmul` is wrong on M5 for many rows (kernels-community#1332) |
| same, `gather_qmm` | 3-bit routed experts (transformers' `experts_offload`, #50717) | MPS, without `gguf_experts` |
| `ggml-org/ggml-quantization` v1: fused dequantize-gemv | `GgufLinear` up to `MAX_GEMV_ROWS` rows (decode) | `gguf_dense` |
| same, `dequantize` + `torch.matmul` | `GgufLinear` above that (prefill) | `gguf_dense` |
| same, `mul_mat_id` | GGUF routed experts on the cache pools, up to 512 routes (decode, short prompts) | `gguf_experts` |
| `ggml-org/ggml-gated-delta-net` v1 | Gated DeltaNet prefill fallback (head dim != 128, or `MOE_STREAMING_GDN_SCAN=0`) | MPS prefill |
| ggml layer kernels (`kernelize_ggml_layers`) | grafted after loading on layers whose hub name ggml maps (`SoftmaxTopKRouter`, `RMSNormZeroCentered`, `Qwen3_5GatedDeltaNet`) | MPS, `dense_bits` set |

## This package's Metal kernels

| Module | Kernels | Replaces | When |
|---|---|---|---|
| `kernels/gguf_mm.py` (`gguf_mm.metal`, generated by `tools/gen_gguf_mm.py` from ggml's block structs, IQ tables and dequantizers, MIT) | `gguf_mm_mpp2_*` (tile GEMM on Metal 4 `matmul2d`, dequantizing GGUF blocks in the kernel, rows read through an index; 32-row tiles and 16-row tails), `gguf_combine_*` (sums each token's routes); `gguf_mm_tiles_*` / `gguf_mm_mpp_*` (earlier variants) | GGUF expert prefill (more than 512 routes) | `gguf_experts`, MPS |
| `kernels/q2_0.py` | `q2_0_mul_mat_id_*` (gather-gemv), `q2_0_dequantize_*` | the Q2_0 expert down projections (30 of 48 layers), which ggml's Metal gemv lacks | `gguf_experts` |
| `kernels/gated_delta_net.py` | `gdn_conv_gates_*` (conv state + conv + SiLU + gates), `gdn_delta_norm_*` (delta rule + gated RMSNorm) | one Gated DeltaNet decode step (~34 ops); its four input projections become one matmul | MPS, 1 token with a cache |
| `kernels/gdn_scan.py` (scan after Strata's `gdn_scan_r`, MIT) | `gdn_conv_silu_*` (causal conv + SiLU, token-major output), `gdn_prep_qk_*` (q/k L2 norm, scale, k.q), `gdn_scan_4_16_*` (the gated delta rule, a lane per state column) | the PyTorch `causal_conv1d_fn` and `torch_chunk_gated_delta_rule` (via `kernels/gdn_prefill.py`) | MPS prefill; `MOE_STREAMING_GGML_GDN_PREFILL=0` turns all of it off |
| `kernels/qsa_decode.py` | `qsa_decode_partial_*` + `qsa_decode_merge_*` (split-K flash decoding over the indexer's selected blocks and the tail only), `qsa_index_q_*` (indexer query RMSNorm + rotary), `qsa_index_scores_*` (block scores; `torch.topk` picks the blocks) | the decode step of `Qwen4ExpTextAttention` past `indexer_budget` keys: the boolean mask over the whole cache, SDPA over every key, and the indexer's ~35 small ops (`indexer.select(..., blocks_only=True)`) | MPS, one token, more keys than the budget |
| `kernels/gated_norm.py` | `gated_rms_norm_*` | `Qwen4ExpTextRMSNormGated` (Gated DeltaNet output norm, silu or sigmoid gate) | MPS, any number of tokens |
| `kernels/hyper_connection.py` | `hc_norm_*`, `hc_act_*`, `hc_mix_*` | `Qwen4ExpTextGatedResidual` (~25 small ops); its projections keep their own matmuls | MPS, any number of tokens |
| `kernels/triton_gather_qmv.py` (Triton) | `gather_qmv` | 3-bit expert decode on CUDA | CUDA |

Not kernels, but also patched: the QSA indexer's token selection is vectorized in PyTorch for causal masks
(`indexer.py`); `mlx_affine.py` is a bit-exact PyTorch MLX (de)quantizer used off MPS (CPU/CUDA experts, converter).

Attention itself is PyTorch SDPA (`attn_implementation="sdpa"`: the indexer's sparse mask rules out the flash kernels).

## Switches

| Environment variable | Effect |
|---|---|
| `MOE_STREAMING_GGML_GDN_PREFILL=0` | Gated DeltaNet prefill on the PyTorch reference (conv and chunked delta rule) |
| `MOE_STREAMING_FAST_INDEXER=0` | the model's own per-query QSA indexer selection |
| `MOE_STREAMING_QSA_DECODE=0` | decode attention past the budget on the model's mask + SDPA (and the indexer's own ops) |
| `GGUF_EXPERTS_COLD_PREFILL` | calls with at least this many tokens (default 512) leave their installs at the LRU's cold end and do not refresh hits; 0 turns it off |
| `MOE_STREAMING_GDN_SCAN=0` | Gated DeltaNet prefill on `ggml-org/ggml-gated-delta-net` instead of `gdn_scan` |
| `GGUF_EXPERTS_TILE_ROWS`, `GGUF_EXPERTS_TAIL_ROWS`, `GGUF_EXPERTS_INSTALL_AHEAD` | GGUF expert prefill tiling (32 / 16 / 1) |
| `GGUF_EXPERTS_PROFILE=1` | host clocks of the GGUF expert prefill in the store stats |
